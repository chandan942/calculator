# Python Calculator

A simple calculator project built with Python as my first programming project.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulo (`%`)
- Division by zero handling
- Invalid operator handling
- Repeat calculations without restarting the program

## Technologies Used

- Python
